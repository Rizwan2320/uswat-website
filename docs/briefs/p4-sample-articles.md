# Brief: Sample articles and the Sample label on article pages (agent 4, 2026-11-18)

- **Why.** The data pack is dropped for now (the project is a competition entry; real data follows only if it is approved). The main agent's rules for fake data: everything marked Sample on screen; fictional names only; emails only on reserved domains; obviously fake phone numbers; generated placeholder images only; invented, labelled dates and figures; real names and structure only where they come from sourced pages.
- **Audit of my earlier Sample data against those rules.** People are "Sample Person NN" (fictional). Emails are on `sample.invalid` (`.invalid` is reserved by RFC 2606, like `.test`). Phones were `+00 000 000000n`: obviously fake, but the rule's example is `000-0000000`, so they become `000-000000n`. Images: none in the seeds. Gap: News, Notices, Events, Jobs and Tenders had no Sample records, so those five pages were empty, and article pages had no Sample marker.
- **Objective.** (1) Sample records for the five article types, seeded by a function like the contact seeds (`scripts/import/seeds/articles.ts`, called from `pnpm seed:sample`). (2) A Sample pill on list cards and a Sample note on article pages for records whose source is on `sample.invalid`. (3) Sample records stay out of the home feeds, so the home page keeps its sourced items.
- **Paths touched.** `scripts/import/seeds/{articles,contacts}.ts`, `apps/web/scripts/seed-sample.ts`; `site/articles/{where,ListingPage,ArticlePage,queries}.ts*` and `site/home/cms.ts`; tests; docs. No collection, schema, token, route or dependency change (three-in-two-out: none added).
- **Rules kept.** Titles start with "Sample", so the label also shows in search results, feeds (left out anyway), and anywhere a title is the only thing shown. Dates are relative to the seed run and invented. Attachment links point at `sample.invalid`. Nothing names a real person, office holder or event. Image fields are left empty: the site already shows the crest on a cream tile when a story has no photo, which is the placeholder; generating pictures would need Media records and storage, which are not worth it for this.
- **Risks.** (1) The seed refuses hosted databases (`assertLocalDatabase`). Putting Sample rows into the shared preview database is the main agent's separate step; I did not change that guard. (2) Dates are relative, so a Sample event or vacancy can pass its date after the seed run; the second run does not refresh published records. (3) A real News story is still reachable at `/posts/{slug}` (reported earlier). (4) Interface words stay English until Urdu is supplied.
- **Not here.** Images (placeholders are the crest), Sample Documents (no collection), Sample records for People-with-photos (blocked: no photos by rule).
- **Tests.** Unit: seed data obeys the rules (names, hosts, phones, dates, unique slugs). Integration: seeds once, second run writes nothing, lists show Sample items, home feeds leave them out. Browser: `/news`, `/notices`, an article, 1440 and 390 px, both directions, axe.
