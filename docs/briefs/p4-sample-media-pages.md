# Brief: Sample media, static pages and the Vercel image spike (agent 4, 2026-11-19)

Part 2 of `docs/briefs/a4-sample-content-pack.md` (part 1 is PR #85: articles, tags, merit lists). Stacked on `p4/sample-rules`.

- **Objective.** (1) Generated placeholder images (neutral shapes with the word SAMPLE, no photographs) and one placeholder PDF, each Media row with English and Urdu alt text and rights `owned`; a few articles use them as their hero image so the relation picker and the media library have content. (2) Four Sample static pages (About, Privacy, Terms, Accessibility) so the footer links resolve on the demo and an editor can open a Pages record. (3) The spike the pack brief asks for: what works for images on a Vercel preview.
- **Paths touched.** `scripts/import/seeds/{media,pages}.ts` (new), `apps/web/scripts/seed-sample.ts`, `scripts/import/seeds/articles.ts` (hero images), tracked placeholder files under `apps/web/public/sample-media/` (only if the spike says static addresses work), tests, docs. Nothing under `src/collections`, `src/governance`, `src/migrations`.
- **Rules kept.** Everything is invented and says Sample; the Media rows carry `sourceUrl` on `sample.invalid` (Media is not governed, so it has no `governance.source`). Image files are generated with `sharp` (already a Payload dependency) and the PDF is written by hand as a minimal valid file: no new dependency. No logos, photographs or real people. The Privacy and Terms pages say plainly that they are Sample pages and not the university's policy.
- **Known limits to report.** The Media `alt` field is a single text field, not localised, so English and Urdu alt text sit together in it (the Urdu part is a draft, ADR 0008). The article template does not render `heroImage` yet (T5 has no hero picture), so the images show in the admin and on Pages only.
- **Risks.** (1) Payload makes up to 5 resized copies per image; the files to commit multiply. Keep the source images at 1200 px wide so the larger sizes are skipped. (2) A published page pointing at a draft image: images are created first. (3) Committing generated binaries: small flat PNGs and a tiny PDF only.
- **Spike.** Prediction A4-l is written first. Evidence is a real request to a Vercel preview of this branch (the Vercel tools, not the sandbox's network).
- **Not here.** `pnpm seed:export` (next piece), a storage adapter (slice 3t, P3), Sample People photos (no photographs by rule).
- **Tests.** Unit: placeholder generator produces PNG and PDF bytes with the right signatures and sizes; page data obeys the label rules. Integration: media and pages seed once and again with 0 created; anonymous reads. Browser: the four pages at both sizes and directions, axe.
