# Data dictionary

Generated by `pnpm dictionary:build` from the CMS configuration. Do not edit by hand: change the collection and run it again.

## Rules that hold for every record below

- A collection marked Governed below has the `governance` group (next section): records start as drafts and nothing is public until it is published. Media, Categories, Users, Audit logs, Redirects, Forms, Form submissions and Search results are not governed.
- A fact needs `governance.source` (a URL or a named document) and, once a reviewer verifies it, `verifiedAt`. Only a reviewer can verify; an import or a job cannot.
- Invented data is labelled Sample: its source is on the host `sample.invalid` and its name starts with "Sample". Public pages show a Sample label for it.
- Personal fields (a person's email and photo) have their own visibility, Hidden by default. Contact details found in imported text are removed and counted, not stored.

| Field | Type | Notes |
| --- | --- | --- |
| `status` | select | one of: draft, in_review, approved, published, archived. default: "draft". Draft, In review, Approved, Published or Archived. What you can move it to depends on your role. |
| `ownerOffice` | text | The office accountable for this record (for example "Registrar"). Required to publish. |
| `source` | text | A web address or the name of a document, for example "Notification no. 123, dated 3 March". Needed before this can be published. |
| `verificationStatus` | select | one of: unverified, verified, stale. default: "unverified". Only a reviewer can mark a record Verified. A record that is not verified cannot be published. |
| `verifiedAt` | date | set by the system |
| `reviewDueAt` | date | The date someone should re-check this. Needed to publish a high-impact record. |
| `riskClass` | select | one of: low, standard, high_impact. default: "standard". Choose High impact for fees, admissions, deadlines, merit lists and legal notices. An approver must publish these. |
| `publishAt` | date | Optional. Set the Stage to Approved and this item goes live by itself at this time. |
| `expireAt` | date | Optional. After this time the item is archived and no longer shown. |
| `origin` | select | one of: editor, importer, watcher. default: "editor". set by the system |
| `contentHash` | text | set by the system |
| `sourceContentHash` | text | set by the system |
| `collectedAt` | date | set by the system |
| `pinned` | checkbox | default: false. Notices drop out of the current list after 90 days unless this is ticked and there is no take-down date. Reviewers only. |
| `createdBy` | relationship | -> users. set by the system |
